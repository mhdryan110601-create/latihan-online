Pengaturan Integrasi Google Sheets

Setiap nilai siswa yang selesai dikerjakan akan dikirimkan otomatis ke spreadsheet ini.

Cara Menghubungkan Google Sheet (3 Langkah):

  1. Buat Spreadsheet baru di Google Sheets (beri judul misalnya: Nilai Ujian CBT).
  2. Klik menu Extensions (Ekstensi) → Apps Script.
  3. Hapus semua kode lama, salin (copy) kode script berikut, lalu tempelkan (paste):
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // Jika baris pertama kosong, tambahkan header
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["Tanggal & Waktu", "Nama Siswa", "Kelas", "Nilai Akhir", "Benar", "Salah"]);
    }
    
    sheet.appendRow([
      data.finishTime || new Date().toLocaleString(),
      data.nama,
      data.kelas,
      data.score,
      data.correctCount,
      data.incorrectCount
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({result: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({result: "error", error: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Klik Deploy (Terapkan) → New deployment (Terapkan baru).
  2. Pilih Jenis: Web app (Aplikasi web).
  3. Atur Who has access (Siapa yang memiliki akses) menjadi: Anyone (Siapa saja).
  4. Klik Deploy, izinkan akses akun Google, lalu salin Web app URL dan tempelkan pada variabel DEFAULT_GSHEET_URL di dalam berkas HTML ini!
